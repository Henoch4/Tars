  It will NOT go live by itself — live requires ALLOW_LIVE=true + restart, and
  only after the G1 gate (see §7).
- Discovery: DexScreener (primary while Blur websocket is down, see §4.6). 10
  candidates per cycle.
- Enrichment (`scripts/meme_runner.py::_enrich`): DexScreener (price, liquidity,
  volume, age, mcap, graduation) + Helius (holder set, authorities, chain truth)
  + RugCheck (creator identity, rugged verdict) + Jupiter (price fallback and,
  new today, round-trip sellability).
- Filter (`src/meme_satellite.py::scream_filter`) is a strict ordered pipeline.
  Doctrine: MISSING DATA = REJECT ("SKIP default"), never default-pass. So a
  data gap and a real risk both surface as `passed=False` — you must read
  `rejected_by` to tell them apart. That distinction is everything in §3.
- Audit: append-only blotter at data/meme_satellite/blotter.jsonl (one JSON line
  per screen: passed, rejected_by, reasons[]). The `reasons[]` array is the
  audit trail; the LAST "X unobserved" note names the gate that killed the row.
- No secrets in this file. Wallet keys/API creds live only in env
  (/etc/tars/agent.env on the VPS, .env locally, both gitignored).

2. THE GATE PIPELINE (exact thresholds, from source)
--------------------------------------------------------------------------------
Order and semantics per `scream_filter` (src/meme_satellite.py). Read codes are
the values you see in the blotter / diagnose output.

  Gate 0  rugcheck_rugged is TRUE  -> reject("rugged_confirmed")   [independent
          RugCheck verdict wins over everything else]
  Floor   holder_count < MIN_HOLDERS (10) -> reject("too_few_holders")
          [top-10 concentration of <10 holders is mathematically vacuous]
  Gate 1  graduated is False/absent -> reject("unconfirmed")
  Gate 2  creator_past_rugs > MAX_PAST_RUGS_CREATOR (0) -> reject("creator_history")
          creator_past_rugs ABSENT -> NOTE only (Q1 SHIPPED 2026-10-17; was reject)
  Gate 3  top10_hold_pct > MAX_TOP10_HOLD_PCT (50) -> reject("holder_concentration")
          top10_hold_pct ABSENT -> reject("missing_data")
  Gate 3b creator_hold_pct > MAX_CREATOR_HOLD_PCT (10) -> reject("insider_heavy")
          creator_hold_pct ABSENT -> reject("missing_data")   [Q2 pending — §11]
  Gate 4  buy_tax_pct > MAX_BUY_TAX_PCT (5) or sell_tax_pct > MAX_SELL_TAX_PCT (10)
            -> reject("honeypot_tax")
          if BOTH taxes absent -> use measured Jupiter round-trip:
            round_trip_cost_pct > MAX_ROUND_TRIP_COST_PCT (15) -> reject("honeypot_tax")
            round_trip_cost_pct ABSENT -> reject("missing_data")
  Gate 5  liquidity_usd < MIN_LIQUIDITY_USD (20,000) -> reject("thin_liquidity")
          liquidity_usd ABSENT -> reject("missing_data")
  Gate 6  mcap_usd < MIN_MCAP_USD (10,000) -> reject("thin_mcap")

  NOTES ONLY — appear in reasons[] but NEVER reject:
    lp_locked, mint_authority_renounced, freeze_authority_renounced, age_s
    (measured non-predictive, demoted Oct 2026), creator_past_rugs-ABSENT
    (demoted 2026-10-17 by Q1), and organic_score (Jupiter bundledness read).
    (regression test: tests/test_meme_satellite.py::
     test_demoted_checks_note_but_never_gate)

Other constants that matter for your analysis:
  MAX_CREATOR_HOLD_PCT = 10.0     MIN_LIQUIDITY_USD   = 20_000.0
  MAX_BUY_TAX_PCT      = 5.0      MIN_MCAP_USD        = 10_000.0
  MAX_SELL_TAX_PCT     = 10.0     MIN_HOLDERS         = 10
  MAX_ROUND_TRIP_COST_PCT = 15.0  MIN_ENTRY_USD       = 5.0
  MAX_PAST_RUGS_CREATOR = 0       MAX_TOP10_HOLD_PCT  = 50

9. GLOSSARY (for anyone reading the numbers cold)
--------------------------------------------------------------------------------
- graduated: token completed the pump.fun-style bonding curve and migrated to a
  real pool (PumpSwap/Raydium). Gate 1 requires it.
- rejected_by: the FIRST failing GATE's code. missing_data = a required field was
  absent (SKIP-default reject), NOT evidence of risk. Read reasons[] for which.
- reasons[]: audit trail; the LAST "<field> unobserved" note names the fatal gap.
- round_trip_cost_pct: measured cost (%) to buy $25 of the mint and sell it back,
  via live Jupiter quotes. Honeypot/sell-block shows as ~100.
- top10_hold_pct: share of supply held by the 10 largest non-vault accounts.
- deployer_history: our own per-creator prior-rug tally, bootstrapped from
  RugCheck verdicts as mints are screened (empty at cold start).
- G1 clock: the paper-to-live gate: >=7 days AND >=30 completed round-trips,
  net-positive after fees.
